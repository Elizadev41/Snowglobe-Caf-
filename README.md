# Snowglobe Cafe

## About

I made Snowglobe Cafe as a cozy winter-themed cafe website. 

The website lets you browse winter drinks, build a custom drink, and keep track of your order through a cart page. I focused on making the project feel like a real cafe ordering experience while keeping the design casual and easy to use.

Snowglobe Cafe includes:

- A featured drinks homepage
- A full seasonal menu
- Warm, cold, and sweet drink categories
- A custom drink builder
- A cart page for viewing orders
- Simple ordering interactions

## Features

When you open Snowglobe Cafe, you start on a homepage with featured drinks and links to the menu or drink builder.

The menu page includes:

- Winter drink cards with photos and prices
- Filters for warm, cold, and sweet drinks
- Select drink buttons
- A small order preview

The drink builder lets you choose:

- Small, medium, or large sizes
- Different drink bases
- Up to six flavors
- Up to six toppings
- Different finishes

Custom drink pricing includes size upgrades and extra flavors or toppings. The maximum price for one custom drink is $20.00 CAD.

The cart page saves menu drinks and custom drinks using Local Storage. You can see your full order, remove items, view the total, and use the checkout button for a simple confirmation.

## Tech Stack

**HTML5.** I used this to create the homepage, menu page, drink builder, and cart page.

**CSS3.** I used this to style the cafe, menu cards, drink builder, responsive layouts, buttons, and order panels.

**Vanilla JavaScript.** This is what makes the filters, drink selections, pricing, cart, and checkout interaction work.

**Browser APIs.** I used Local Storage to save orders while moving between pages.
